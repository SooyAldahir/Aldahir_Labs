Aplicación móvil para el Programa EDI 301

Una app multiplataforma para la gestión institucional de docentes y alumnos en la Universidad Linda Vista, respaldada por una API REST propia y publicada en las tiendas oficiales.

¿Qué necesidad buscaba resolver?

El Programa EDI 301 de la Universidad Linda Vista necesitaba una forma práctica de gestionar la información institucional de docentes y alumnos, accesible desde el teléfono y disponible en ambos sistemas operativos.

Una app multiplataforma con backend propio.

Una aplicación móvil con Flutter, con un único código base para Android e iOS, conectada a una API REST en Node.js y Express que centraliza la comunicación con la base de datos.

Del modelo de datos a la tienda.

  • Diseño y desarrollo de la aplicación móvil multiplataforma con Flutter.
  • Implementación de la API REST con Node.js y Express para la comunicación entre la app y la base de datos.
  • Participación en el diseño de la estructura de datos y en la integración entre frontend y backend.
  • Publicación de la aplicación en Google Play Store y App Store.

Publicada e investigada.

La aplicación se publicó en Google Play Store y App Store, y se convirtió en la base de una investigación presentada en congresos científicos y de una publicación universitaria.
